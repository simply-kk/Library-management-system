# 📚 PageFlow - Library Management System

A full-stack backend Library Management System built using **Spring Boot**, **Spring Data JPA**, and **MySQL**. The project automates library operations such as book management, student management, book issue/return, CSV imports, and email notifications.

## 🚀 Features

### 📖 Book Management

* Add Book
* Add Multiple Books
* Get All Books
* Get Book By ID
* Update Book
* Delete Book
* Delete Multiple Books
* Delete All Books
* Search by Title
* Search by Author
* Search by Category
* Pagination
* Sorting

### 👨‍🎓 Student Management

* Create Student
* Get All Students
* Get Student By ID
* Update Student
* Delete Student
* Search by Name
* Search by Email
* CSV Student Import
* Welcome Email on Registration

### 📚 Library Operations

* Issue Book
* Return Book
* Prevent Duplicate Book Issue
* Check Book Availability
* Update Available Copies
* Student Issue History
* Book Issue History
* Transaction History

### 📧 Email Notifications

* Welcome Email for New Students
* Book Issue Confirmation Email
* Book Return Confirmation Email

### 📂 CSV Import

* Bulk Book Import
* Bulk Student Import
* Partial Import Support
* Error Reporting
* Imported & Skipped Record Count

### ✅ Validation & Exception Handling

* Bean Validation
* Global Exception Handling
* Custom Exceptions
* Meaningful Error Responses
